## 推荐操作顺序

完成 [部署和初始化](installation.md) → 添加账号并验证登录 → 配置任务 → 按需启用插件和通知 → 在总览与日志确认执行结果。

详细行为以 [完整使用指南](user-guide.md) 为准。
